# Competitors / What Already Exists

**Reviewed:** 2026-11-15. This is a bounded desk review, not an exhaustive feature audit or proof of an uncontested market. See [source limitations](../documentation-audit.md).

## Landscape

- **Event platforms** support discovery, registration, communities, and sometimes chat.
- **Friendship apps** such as BFF support individual discovery and groups.
- **Curated outings** such as Timeleft and 222 arrange introductions; Timeleft already supports inviting connections to another booking.
- **Clubs** offer recurring activities; newcomer support varies by organizer.

Firefly's proposed distinction is consent-based introductions and recurring pods layered onto existing host-run events. This is a hypothesis about useful execution, not a feature combination proven absent everywhere else.

## Comparison of evidenced overlap

“Not established” means this review did not verify the feature; it does not mean the feature is absent.

| Product | Discovery / context | Social coordination | Repeat contact |
|---------|---------------------|---------------------|----------------|
| Luma | Events and calendars | Guest chat and host tools | Recurring communities; dedicated friendship pods not established |
| Eventbrite | Event marketplace | Host communications; full attendee feature review pending | Dedicated mutual friendship workflow not established |
| Meetup | Interest groups | Group discussions and events | Recurring groups |
| Partiful | Invitations and public Explore | Co-attendance graph; Crush reveals mutual romantic interest | New invitations; recurring-pod mechanism not established |
| BFF | People and groups | Chats and planning tools | Group activities |
| Timeleft | Its curated outings | Group chat and connections | Invite connections to a subsequent booking |
| 222 | Curated outings | Plans with friends and new matches advertised | Detailed mechanics not verified |
| Pie | Host-created plans | Chat, RSVPs, photos, tickets | Repeated plans with friends/community |
| Conference tools | Event attendees | Matchmaking and scheduled meetings | Access and follow-up depend on product/configuration |
| Clubs | Shared activity | Host-dependent introductions | Recurring attendance |
| **Firefly (proposed)** | Partner recurring events | Consensual pods and mutual connections | Suggested next event and re-podding; untested |

App access and event admission are different costs. A free app does not imply all events are free. No head-to-head friendship-outcome comparison was found.
