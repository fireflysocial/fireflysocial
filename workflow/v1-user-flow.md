# User Flow (v1 Draft)

> Draft. To be modified and strengthened further. Open issues are tracked in [open-gaps.md](open-gaps.md).

1. **Onboarding**
   * Firefly learns the user's interests, background, and the kind of people they hope to meet.
   * The user adds the social accounts they are willing to share (LinkedIn, Instagram). These stay private until the user chooses to share them.

2. **Discover events**
   * Firefly pulls active events from platforms like Luma and Eventbrite and shows the ones that match the user's interests.
   * Each event shows how many Firefly users are going, so the user knows others there are also looking to meet people.

3. **Sign up through Firefly**
   * The user registers for the event and marks themselves as open to meeting people there.

4. **At the event**
   * Firefly shows which attendees are Firefly users, along with shared interests and a conversation opener for each.
   * People find each other and talk in person.

5. **After the event**
   * Firefly asks each user who they met.
   * Each user privately chooses who they would like to stay in touch with.
   * When two people choose each other, Firefly exchanges their socials. If the choice isn't mutual, nobody is told.

6. **Keep the connection going**
   * Firefly recommends upcoming events that the user's new connections are also attending, so they have a reason to meet again.
